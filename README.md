# Product 1 — 차량용 QR 연락판

차량에 전화번호를 직접 적어두는 대신, QR 코드를 스캔해 차주에게 전화할 수 있는 모바일 웹페이지입니다.

개발 경험이 없어도 기본 템플릿을 복제한 뒤 차량번호, 전화번호, 문구를 변경해 사용할 수 있습니다. 화면의 컬러와 디자인도 원하는 방식으로 커스텀할 수 있습니다.

## 데모 체험

[Product 1 데모 체험하기](https://product1-demo.pages.dev/)

데모에는 예시 차량번호와 존재하지 않는 전화번호가 적용되어 있습니다.

## 주요 기능

- QR 코드로 모바일 연락 페이지 접속
- 차량번호 확인
- 버튼을 눌러 차주에게 전화 연결
- 차량번호·전화번호·안내 문구 변경
- 컬러와 화면 디자인 커스텀
- Cloudflare Pages를 통한 무료 배포

## 파일 구성

| 파일 | 역할 |
|---|---|
| `config.js` | 차량번호, 전화번호, 안내 문구 설정 |
| `style.css` | 컬러, 글꼴, 버튼 등 화면 디자인 |
| `index.html` | 화면의 기본 구조와 전화 연결 기능 |
| `favicon.svg` | 브라우저에 표시되는 아이콘 |

## 내 정보로 변경하기

`config.js` 파일을 열고 따옴표 안의 정보만 변경합니다.

```javascript
window.PRODUCT_CONFIG = {
  pageTitle: "차주 연락",
  plateNumber: "123가 5678",
  phoneNumber: "01012345678",
  messageTitle: "차량 이동이 필요하신가요?",
  callButtonText: "전화 걸기",
  footerText: "연결 시 통신사 통화료가 발생할 수 있습니다"
};
```

- `plateNumber`: 자신의 차량번호
- `phoneNumber`: 연결할 전화번호
- `messageTitle`: 화면에 표시할 안내 문구
- `callButtonText`: 통화 버튼 문구
- `footerText`: 화면 하단의 안내 문구

전화번호는 하이픈 없이 숫자만 입력해주세요.

## 디자인 변경하기

`style.css` 상단의 색상 값을 변경하면 기본 디자인을 커스텀할 수 있습니다.

```css
:root {
  --bg-primary: #f4f6f8;
  --bg-card: #ffffff;
  --bg-plate: #f8f9fa;
  --text-primary: #17212b;
  --text-secondary: #747c86;
  --bg-action: #17212b;
  --text-action: #ffffff;
}
```

색상 코드는 `#`으로 시작하는 6자리 값을 사용합니다.

## 제작 과정

1. 이 템플릿을 자신의 GitHub 계정으로 복제합니다.
2. `config.js`에서 차량번호와 전화번호를 변경합니다.
3. 필요하면 `style.css`에서 컬러와 디자인을 변경합니다.
4. Cloudflare Pages로 무료 배포합니다.
5. 배포된 주소로 QR 코드를 만듭니다.
6. 실제 휴대전화로 QR 스캔과 통화 연결을 테스트합니다.
7. QR을 출력해 차량에 설치합니다.

자세한 제작 방법과 다양한 차량 설치 방식은 별도의 Notion 가이드에서 안내할 예정입니다.

## 사용 전 확인사항

- 배포 전에 차량번호와 전화번호가 정확한지 확인해주세요.
- 실제 휴대전화에서 통화 버튼이 정상적으로 작동하는지 테스트해주세요.
- 다른 사람의 전화번호를 동의 없이 사용하지 마세요.
- 웹페이지의 통화 링크에 입력한 전화번호는 페이지 소스에서 확인될 수 있습니다.
- 전화번호 노출이 걱정된다면 안심번호나 별도의 연락 수단을 검토해주세요.
- QR이 운전자의 시야를 방해하지 않도록 설치해주세요.
- 유리 반사나 차량 내부 구조 때문에 QR 인식이 방해되지 않는지 확인해주세요.
